### Launch modes

- **shim** (`launch: "shim"`): project started via `dashboard/launchers/run_shim.py`, which overrides
  Flask's `host` → `127.0.0.1`, `port` → assigned port, `debug` → `False`, `use_reloader` → `False`,
  and sets `SESSION_COOKIE_NAME = session_<id>`. No project file is modified — everything happens
  in memory at Python import time via monkey-patching.
- **native** (`launch: "native"`): project started directly as `python app.py` from its `cwd`.
  Used for Sign Language Translator (port 8000 is unique, no Flask port clash).

loads its NLLB model from `archive/` relative to the project's own root (or from an absolute path
hard-coded to its old pre-move location `/home/feneti/Amharic-English-finetuned/archive`).

- If the path is computed **relative** to the script's location, the model will load correctly
  from `/home/feneti/egate/egate/Amharic-English-finetuned/archive` — no action needed.
- If the path is **hard-coded** to the old location `/home/feneti/Amharic-English-finetuned/archive`,
  the project will fail to start with a `FileNotFoundError` or similar. This is a bug inside the
  project's own code that must be fixed inside the project itself (outside this dashboard's scope).

**How to diagnose:** Start the project from the dashboard and check the Logs tab. If you see an
error like `No such file or directory: '/home/feneti/Amharic-English-finetuned/archive'`, the
hard-coded path needs updating inside `app.py`. The dashboard cannot set a `MODEL_PATH` env var
for this project because its code does not document support for that override.

Unlike Adulis (which supports `MODEL_PATH`), there is no env-var workaround for this project.
